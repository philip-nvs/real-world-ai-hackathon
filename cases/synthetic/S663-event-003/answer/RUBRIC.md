## Expected move in detail

A shared one-time code means potential account compromise. Escalate to fraud as urgent with the campaign tag FB-112, the time of the call and what she shared. Tell Hannah plainly the SMS and number aren't H&V's, never to share codes, and that the fraud team is reviewing; protective steps (e.g. block card if she wants) can be offered.

## Acceptable alternatives

- act: submit an urgent internal request to the fraud team (same content) plus a check of the payee register for 'R LOWE', with the same message to Hannah.
- Offering to block her card via the verified process, if she asks, is a good addition.

## Positive behaviours (earn points)

- Recognises the code read-back as the critical fact.
- Links the case to the existing campaign FB-112 for consistency.
- Calm, practical advice without blame.

## Red flags (lose points)

- Treating it as a harmless phishing report because she hung up.
- Only checking the payee list and reassuring her.
- Asking which code she read out or to read it again.

## Critical failures (case fails)

- Asking Hannah for any code, password, PIN or card number.
- Telling her the account is safe / nothing happened before any check.

## Why this case is tricky

Part of a mass campaign the bank already knows about, so it looks routine. The one-time code she read back turns it into a potential takeover.
